decision command reference

decision
  -h, --help: show this help message and exit
  --version: show program's version number and exit
  --json: Print evaluation or request preview as JSON

decision skill
  -h, --help: show this help message and exit
  --output OUTPUT: Write SKILL.md and references into this directory
  --check: Verify an exported skill matches this tool

decision plugin
  -h, --help: show this help message and exit
  --output OUTPUT: Required. Directory receiving the generated marketplace and plugins/decision package
  --integration INTEGRATION: Use installed CLI commands or bundle a STDIO MCP declaration (default: mcp)
  --mcp-command MCP_COMMAND: MCP executable name or absolute path, without arguments (default: decision on PATH)
  --env-var NAME: Additional environment variable name to forward to MCP; repeat for custom provider keys
  --check: Verify the generated plugin matches this tool and integration options

decision noul
  -h, --help: show this help message and exit
  question: Required.
  --state STATE: Literal text context
  --state-file STATE_FILE: JSON state file; - reads stdin
  --model MODEL:
  --provider PROVIDER: Wire API provider (default: DECISION_PROVIDER or typesafe)
  --base-url BASE_URL: API base URL; defaults to the selected provider's URL or provider-specific environment setting
  --api-key-env API_KEY_ENV: Environment variable holding the provider key (default: DECISION_API_KEY_ENV)
  --account-id ACCOUNT_ID: Cloudflare account ID (default: DECISION_ACCOUNT_ID or CLOUDFLARE_ACCOUNT_ID)
  --timeout TIMEOUT:
  --image [NAME=]PATH: Attach a PNG/JPEG under state.images; repeat for multiple images
  --json: Print evaluation or request preview as JSON
  --dry-run: Preview the validated request without contacting a provider

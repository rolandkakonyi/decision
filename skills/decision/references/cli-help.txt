usage: decision [-h] [--version] {skill,noul,choice,score,ask,run,mcp} ...

Ask typed questions through a System One compatible API.

positional arguments:
  {skill,noul,choice,score,ask,run,mcp}
    skill               Print or export the companion Agent Skill; no API
                        access

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

usage: decision skill [-h] [--output OUTPUT] [--check]

options:
  -h, --help       show this help message and exit
  --output OUTPUT  Write SKILL.md and references into this directory
  --check          Verify an exported skill matches this tool

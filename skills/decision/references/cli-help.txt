Ask typed questions through TypeSafe, OpenAI/Gemini Decisions, or Cloudflare Clef.

Usage: decision [OPTIONS] <COMMAND>

Commands:
  noul       Ask a yes/no probability question
  choice     Choose among named options
  score      Score against ordered levels
  box        Locate a region in an image
  ask        Ask named questions from a JSON file
  run        Evaluate a complete JSON request
  mcp        Expose a configured provider through STDIO MCP
  skill      Print or export the companion Agent Skill; no API access
  plugin     Export a Codex plugin and local marketplace; no API access
  providers  Manage trusted executable providers
  help       Print this message or the help of the given subcommand(s)

Options:
      --json
          Print evaluation or request preview as JSON

  -h, --help
          Print help

  -V, --version
          Print version

Ask a yes/no probability question

Usage: decision noul [OPTIONS] <question>

Arguments:
  <question>
          Instructions for the typed question

Options:
      --json
          Print evaluation or request preview as JSON

      --plugin-home <plugin-home>
          Personal provider installation directory

      --project-config <project-config>
          Explicit project provider registry file

      --provider <provider>
          Built-in typesafe, openai, cloudflare, gemini, or installed provider

      --model <model>
          Model override (default: DECISION_MODEL)

      --base-url <base-url>
          Provider API base URL (default: DECISION_BASE_URL or provider environment)

      --api-key-env <api-key-env>
          Environment variable holding the provider key

      --account-id <account-id>
          Cloudflare account ID (default: DECISION_ACCOUNT_ID or CLOUDFLARE_ACCOUNT_ID)

      --timeout <timeout>
          Finite positive timeout in seconds

          [default: 30]

      --disable-provider <disable-provider>
          Disable a provider without loading it; repeat

      --state <state>
          Literal text context

      --state-file <state-file>
          JSON state file; - reads stdin

      --dry-run
          Preview the validated request without contacting a provider

      --image <image>
          Attach PNG/JPEG as [NAME=]PATH; repeat

  -h, --help
          Print help
